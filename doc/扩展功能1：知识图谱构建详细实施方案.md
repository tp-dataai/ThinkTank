# 阶段一：基础设施

## 1.1 明确网络拓扑（先做，决定后面所有地址）

VMware 有两种常用方式，二选一：

### 方案 A：桥接模式（推荐）

VM 获得局域网独立 IP，Windows 直接访问 `VM_IP:7687`。

VM 内执行：

```bash
hostname -I
# 例如输出 192.168.1.105
```

Windows 上 `.env` 写：

```env
NEO4J_URI=bolt://192.168.1.105:7687
```

### 方案 B：NAT + 端口转发

VMware → 编辑 → 虚拟网络编辑器 → VMnet8 → NAT 设置 → 端口转发，添加：

| 主机端口 | 类型 | 虚拟机 IP | 虚拟机端口 |
|---|---|---|---|
| 7474 | TCP | VM 当前 IP | 7474 |
| 7687 | TCP | VM 当前 IP | 7687 |

Windows 上 `.env` 写：

```env
NEO4J_URI=bolt://127.0.0.1:7687
```

> 注意：NAT 端口转发模式下，Windows 侧不要用 VM IP；桥接模式下不要用 127.0.0.1。VM IP 若为 DHCP，建议在 VMware 里绑定静态 IP 或在路由器做 DHCP 保留，避免重启后地址变化。

**验收：** Windows PowerShell 执行

```powershell
Test-NetConnection 192.168.1.105 -Port 7687
# 或 NAT 模式
Test-NetConnection 127.0.0.1 -Port 7687
```

必须看到 `TcpTestSucceeded : True`。

## 1.2 在 VM 内启动 Neo4j 容器

### 步骤 1：确认 Docker

```bash
docker --version
docker ps
```

### 步骤 2：拉取镜像

```bash
docker pull neo4j:5-community
```

固定使用 **Neo4j 5 Community**，兼容本方案所有 Cypher 和约束语法。

### 步骤 3：创建数据卷

```bash
docker volume create neo4j_kg_data
```

数据卷保证容器删除/重建后图谱不丢。

### 步骤 4：启动容器

```bash
docker run -d \
  --name neo4j-kg \
  --restart unless-stopped \
  -p 7474:7474 \
  -p 7687:7687 \
  -e NEO4J_AUTH=neo4j/<强密码，至少8位> \
  -e NEO4J_server_memory_heap_initial__size=512m \
  -e NEO4J_server_memory_heap_max__size=1G \
  -e NEO4J_server_memory_pagecache_size=512m \
  -v neo4j_kg_data:/data \
  neo4j:5-community
```

说明：

- `7474`：Neo4j Browser；
- `7687`：Bolt 协议，Python 项目连接用；
- `NEO4J_AUTH` 只在**数据卷第一次初始化**时生效，后续改密码不会自动更新；
- `--restart unless-stopped`：VM 重启后容器自动启动；
- 内存参数按 VM 内存调整，VM 至少给 4GB。

### 步骤 5：确认容器状态

```bash
docker ps
docker logs -f neo4j-kg
```

看到 `Started.` 后 `Ctrl+C` 退出日志跟随。

### 步骤 6：VM 内自测

```bash
docker exec -it neo4j-kg cypher-shell -u neo4j -p '<密码>' "RETURN 'ok' AS status;"
```

预期返回：

```text
status
"ok"
```

## 2.2 实现顺序

### 步骤 1：写常量与驱动初始化

```python
import hashlib
from datetime import datetime

from neo4j import GraphDatabase

from thinktank.config.config import Neo4jConfig
from thinktank.tool.logger import logger

_driver = None

_SCHEMA_STATEMENTS = [
    """CREATE CONSTRAINT entity_id_unique IF NOT EXISTS
       FOR (e:Entity) REQUIRE e.entity_id IS UNIQUE""",
    """CREATE INDEX entity_item_name IF NOT EXISTS
       FOR (e:Entity) ON (e.item_name)""",
    """CREATE INDEX rel_item_name IF NOT EXISTS
       FOR ()-[r:RELATED]-() ON (r.item_name)""",
    """CREATE INDEX rel_file_title_id IF NOT EXISTS
       FOR ()-[r:RELATED]-() ON (r.file_title_id)""",
]


def get_neo4j_driver():
    global _driver
    if _driver is None:
        _driver = GraphDatabase.driver(
            Neo4jConfig.neo4j_uri,
            auth=(Neo4jConfig.neo4j_user, Neo4jConfig.neo4j_password),
        )
        _driver.verify_connectivity()
        with _driver.session(database=Neo4jConfig.neo4j_database) as session:
            for statement in _SCHEMA_STATEMENTS:
                session.run(statement).consume()
        logger.info("Neo4j 连接成功，图谱约束/索引已就绪")
    return _driver
```

**验收：** 首次调用后，Neo4j Browser 执行 `SHOW CONSTRAINTS;` 能看到 `entity_id_unique`，`SHOW INDEXES;` 能看到 3 个索引。

### 步骤 2：实现唯一键函数

```python
def make_entity_id(item_name, name):
    return hashlib.md5(f"{item_name}|{name}".encode("utf-8")).hexdigest()


def make_rel_id(file_title_id, source, relation, target):
    raw = f"{file_title_id}|{source}|{relation}|{target}"
    return hashlib.md5(raw.encode("utf-8")).hexdigest()
```

规则：

- 实体按 `item_name` 隔离，避免「孩子」「3岁」跨主题合并成超级节点；
- 关系 id 不含 `description`，同一三元组在同一文件内只保留一条，重复抽取不会产生重复边；
- `rel_id` 同时作为 RRF 的去重键，必须跨进程稳定。

**验收：**

```python
assert make_entity_id("小学生睡眠", "6-12岁") == make_entity_id("小学生睡眠", "6-12岁")
assert make_rel_id("fid", "A", "导致", "B") == make_rel_id("fid", "A", "导致", "B")
```

### 步骤 3：实现规范化

```python
_ALLOWED_TYPES = {"主题", "年龄段", "方法", "问题", "表现", "建议", "概念"}


def _normalize(file_title_id, file_title, item_name, entities, relations):
    create_date = str(datetime.now())
    entity_map = {}

    def add_entity(name, entity_type):
        name = (name or "").strip()
        if not name:
            return
        entity_type = (entity_type or "").strip()
        if entity_type not in _ALLOWED_TYPES:
            entity_type = "概念"
        entity_map[name] = {
            "entity_id": make_entity_id(item_name, name),
            "name": name,
            "type": entity_type,
            "item_name": item_name,
            "file_title": file_title,
            "file_title_id": file_title_id,
            "create_date": create_date,
        }

    for entity in entities:
        add_entity(entity.get("name"), entity.get("type"))
    add_entity(item_name, "主题")  # 强制包含主体，防止 LLM 漏抽

    relation_map = {}
    for relation in relations:
        source = (relation.get("source") or "").strip()
        target = (relation.get("target") or "").strip()
        label = (relation.get("relation") or "").strip()
        description = (relation.get("description") or "").strip()[:200]
        if not source or not target or not label or source == target:
            continue
        add_entity(source, "概念")   # 端点缺失自动补全
        add_entity(target, "概念")
        rel_id = make_rel_id(file_title_id, source, label, target)
        relation_map[rel_id] = {
            "rel_id": rel_id,
            "source_id": entity_map[source]["entity_id"],
            "target_id": entity_map[target]["entity_id"],
            "relation": label,
            "description": description,
            "item_name": item_name,
            "file_title": file_title,
            "file_title_id": file_title_id,
            "create_date": create_date,
        }

    return list(entity_map.values()), list(relation_map.values())
```

异常数据处理规则：

| 情况 | 处理 |
|---|---|
| 实体名为空/空格 | 丢弃 |
| 实体类型不在白名单 | 归为「概念」 |
| 主体未出现在实体列表 | 自动补为「主题」 |
| 关系端点为空的任一端 | 丢弃 |
| 关系两端相同 | 丢弃 |
| 关系端点在实体列表不存在 | 自动补为「概念」 |
| 同一三元组重复 | 按 `rel_id` 去重，后写覆盖 |
| description 超长 | 截断到 200 字 |

### 步骤 4：实现写图事务

```python
def save_graph(file_title_id, file_title, item_name, entities, relations):
    entity_rows, relation_rows = _normalize(
        file_title_id, file_title, item_name, entities, relations
    )
    with get_neo4j_driver().session(database=Neo4jConfig.neo4j_database) as session:
        session.execute_write(_write_tx, file_title_id, entity_rows, relation_rows)
    logger.info(
        f"Neo4j 写入完成：实体 {len(entity_rows)} 个，关系 {len(relation_rows)} 条"
    )
    return len(entity_rows), len(relation_rows)


def _write_tx(tx, file_title_id, entity_rows, relation_rows):
    # 1. 删除该文件的旧关系，保证重复导入幂等
    tx.run(
        "MATCH ()-[r:RELATED {file_title_id: $fid}]->() DELETE r",
        fid=file_title_id,
    ).consume()

    # 2. MERGE 实体
    tx.run(
        """
        UNWIND $entities AS e
        MERGE (n:Entity {entity_id: e.entity_id})
        SET n.name = e.name,
            n.type = e.type,
            n.item_name = e.item_name,
            n.file_title = e.file_title,
            n.file_title_id = e.file_title_id,
            n.create_date = e.create_date
        """,
        entities=entity_rows,
    ).consume()

    # 3. MERGE 关系
    tx.run(
        """
        UNWIND $relations AS rel
        MATCH (s:Entity {entity_id: rel.source_id})
        MATCH (t:Entity {entity_id: rel.target_id})
        MERGE (s)-[r:RELATED {rel_id: rel.rel_id}]->(t)
        SET r.relation = rel.relation,
            r.description = rel.description,
            r.item_name = rel.item_name,
            r.file_title = rel.file_title,
            r.file_title_id = rel.file_title_id,
            r.create_date = rel.create_date
        """,
        relations=relation_rows,
    ).consume()

    # 4. 清理本文件遗留的孤立实体（可选）
    tx.run(
        "MATCH (e:Entity {file_title_id: $fid}) WHERE NOT (e)--() DELETE e",
        fid=file_title_id,
    ).consume()
```

事务边界要点：

- **删除旧边、写实体、写关系、清理孤立节点必须在同一事务**，`session.execute_write` 保证原子性和瞬时故障重试；
- 每一条 `tx.run(...).consume()` 都要消费结果，避免同一事务里结果未读完；
- 删除以 `file_title_id` 为范围，不会影响其他文件的关系；
- 实体按 `entity_id` MERGE，同 `item_name` 下跨文件共享实体。

### 步骤 5：实现图检索候选查询

```python
def search_relations(item_names, limit=50):
    query = """
    MATCH (s:Entity)-[r:RELATED]->(t:Entity)
    WHERE r.item_name IN $item_names
    WITH s, r, t,
         COUNT { (s)-[:RELATED]-() } + COUNT { (t)-[:RELATED]-() } AS degree
    RETURN s.name AS source,
           r.relation AS relation,
           t.name AS target,
           r.description AS description,
           r.file_title AS file_title,
           r.rel_id AS rel_id,
           degree
    ORDER BY degree DESC, r.rel_id
    LIMIT $limit
    """
    records, _, _ = get_neo4j_driver().execute_query(
        query,
        item_names=item_names,
        limit=limit,
        database_=Neo4jConfig.neo4j_database,
    )
    return [record.data() for record in records]
```

设计说明：

- 用 `item_name IN` 锚定，和 Milvus 的 `item_name in [...]` 过滤语义一致；
- 返回 50 条候选，交给查询节点做关键词精排；
- `degree` 作为兜底排序：实体连接越多越核心；
- 全部使用参数化查询，不做字符串拼接。

## 3.2 新建导入节点

新建 [node_graph_extraction.py](thinktank/import_process/nodes/node_graph_extraction.py)：

```python
import json

from thinktank.config.prompt import (
    GRAPH_EXTRACT_SYSTEM_PROMPT,
    GRAPH_EXTRACT_USER_TEMPLATE,
)
from thinktank.import_process.base import NodeBase
from thinktank.import_process.state import ImportGraphState
from thinktank.tool.logger import logger
from thinktank.tool.neo4j_tool import save_graph
from thinktank.tool.tool_llm_init import get_llm_init


class NodeGraphExtraction(NodeBase):
    name = "node_graph_extraction"
    batch_max_chars = 4000
    batch_max_chunks = 5

    def process(self, state: ImportGraphState):
        chunks = state.get("chunks") or []
        item_name = state.get("item_name")
        file_title = state.get("file_title")
        file_title_id = chunks[0].get("file_title_id") if chunks else None

        if not (item_name and file_title and file_title_id):
            raise ValueError("图谱抽取缺少 chunks/item_name/file_title_id")

        llm = get_llm_init()
        entities, relations = [], []

        for batch_no, batch in enumerate(self.batch_chunks(chunks), start=1):
            batch_entities, batch_relations = self.extract(
                llm, file_title, item_name, batch
            )
            entities.extend(batch_entities)
            relations.extend(batch_relations)
            logger.info(
                f"图谱批次 {batch_no}：实体 {len(batch_entities)}，"
                f"关系 {len(batch_relations)}"
            )

        entity_count, relation_count = save_graph(
            file_title_id, file_title, item_name, entities, relations
        )
        logger.info(
            f"图谱导入完成：实体 {entity_count}，关系 {relation_count}"
        )
        return {}

    def batch_chunks(self, chunks):
        batch, size = [], 0
        for chunk in chunks:
            text = f"[标题:{chunk.get('title', '')}]\n{chunk.get('content', '')}"
            if batch and (
                size + len(text) > self.batch_max_chars
                or len(batch) >= self.batch_max_chunks
            ):
                yield "\n\n".join(batch)
                batch, size = [], 0
            batch.append(text)
            size += len(text)
        if batch:
            yield "\n\n".join(batch)

    def extract(self, llm, file_title, item_name, context):
        messages = [
            {"role": "system", "content": GRAPH_EXTRACT_SYSTEM_PROMPT},
            {
                "role": "user",
                "content": GRAPH_EXTRACT_USER_TEMPLATE.format(
                    file_title=file_title,
                    item_name=item_name,
                    context=context,
                ),
            },
        ]
        for attempt in range(2):
            res = llm.invoke(messages)
            try:
                data = json.loads(
                    res.content.replace("```json", "").replace("```", "")
                )
                return data.get("entities", []), data.get("relations", [])
            except (json.JSONDecodeError, AttributeError) as e:
                logger.warning(
                    f"图谱 JSON 解析失败（第 {attempt + 1} 次）：{e}"
                )
        raise ValueError("图谱抽取结果无法解析为 JSON")
```

实现要点：

- **LLM 只初始化一次**，所有批次复用（`get_llm_init()` 当前每次调用都会新建客户端）；
- 按 4000 字或 5 个 chunk 分批，控制单次上下文和调用成本；
- 每批 JSON 解析失败重试 1 次，仍失败抛异常，避免静默写入残缺图谱；
- 实体/关系跨批次合并后统一交给 `save_graph` 做规范化和去重；
- 返回 `{}`，不改变现有 state 和下游节点；
- 抽取节点不直接操作 Neo4j，所有图操作收敛在 `neo4j_tool`。

## 4.2 新建图检索节点

新建 [node_search_graph.py](thinktank/query_process/nodes/node_search_graph.py)：

```python
from thinktank.query_process.base import NodeBase
from thinktank.query_process.state import QueryGraphState
from thinktank.tool.logger import logger
from thinktank.tool.neo4j_tool import search_relations


class NodeSearchGraph(NodeBase):
    name = "node_search_graph"
    candidate_limit = 50
    top_k = 10

    def process(self, state: QueryGraphState):
        item_names = state.get("item_names") or []
        rewritten_query = state.get("rewritten_query") or ""
        if not item_names:
            return {"graph_chunks": []}

        try:
            edges = search_relations(item_names, limit=self.candidate_limit)
        except Exception as e:
            # 图检索是增强路径，Neo4j 故障不应让整个问答失败
            logger.error(f"图谱检索失败，降级为空结果：{e}")
            return {"graph_chunks": []}

        query_grams = self.bigrams(rewritten_query)
        scored = []
        for edge in edges:
            text = "".join([
                edge.get("source") or "",
                edge.get("relation") or "",
                edge.get("target") or "",
                edge.get("description") or "",
            ])
            scored.append((len(query_grams & self.bigrams(text)), edge))

        scored.sort(key=lambda item: item[0], reverse=True)

        if any(score > 0 for score, _ in scored):
            scored = [item for item in scored if item[0] > 0][: self.top_k]
        else:
            # 关键词完全不命中时，保留度数排序前 K 条作为兜底
            scored = scored[: self.top_k]

        chunks = [self.to_chunk(edge, score) for score, edge in scored]
        logger.info(f"图谱召回候选 {len(edges)} 条，返回 {len(chunks)} 条")
        return {"graph_chunks": chunks}

    def to_chunk(self, edge, score):
        source = edge.get("source") or ""
        relation = edge.get("relation") or ""
        target = edge.get("target") or ""
        description = edge.get("description") or ""
        content = (
            f"{source} --{relation}--> {target}：{description}"
            if description
            else f"{source} --{relation}--> {target}"
        )
        return {
            "id": edge["rel_id"],
            "title": f"{source} {relation} {target}",
            "content": content,
            "source": "graph",
            "score": float(score),
        }

    @staticmethod
    def bigrams(text):
        text = "".join(ch.lower() for ch in text if ch.isalnum())
        return {text[i:i + 2] for i in range(len(text) - 1)}
```

实现要点：

- `item_names` 为空直接返回空列表（正常情况下路由不会走到这里）；
- Neo4j 异常**软降级**：查询侧图只是增强路径，不能因为图库故障导致整个问答失败；导入侧则硬失败，两边策略不同；
- 检索候选 50 条，用中文二元组交集做相关性排序，取前 10；
- 全部零分时用 Cypher 的度数排序兜底，保证图路径仍有输出；
- 输出 chunk 必须带 `id=rel_id`，供 RRF 去重；
- 输出字段与现有 Milvus 切片对齐：`id/title/content/source/score`。

# 阶段六：故障排查与运维

## 6.1 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ServiceUnavailable: Failed to establish connection` | VM 未启动、容器未启动、IP/端口错、防火墙 | `docker ps`、`hostname -I`、`Test-NetConnection`、放行 7687 |
| `AuthError` | 密码错误；数据卷已用旧密码初始化 | 删卷重建或进容器改密码 |
| Browser 能开但 Bolt 连不上 | NAT 模式用了 VM IP、桥接模式用了 127.0.0.1 | 按 1.1 的模式统一地址 |
| `CREATE INDEX` 语法报错 | Neo4j 版本过低 | 使用 `neo4j:5-community` |
| 关系索引创建失败 | 某些版本/发行版限制 | 删除两条 `rel_*` 索引语句，功能不受影响 |
| 导入任务在「知识图谱抽取」失败 | LLM JSON 无法解析、Neo4j 不可用 | 看日志；重试；检查 Neo4j |
| 查询没有图结果 | 图谱为空、`item_name` 不一致、关键词全不命中 | 用 Cypher 确认 `r.item_name` 与查询 `item_names` 一致 |
| RRF 结果里没有图 id | 图结果排名靠后、Top10 被挤掉 | 调大 `top_k`、调低图权重或检查打分 |
| 两个服务都占用 8001 | 现有代码写死 | 分别启动，或临时改端口（不在本方案范围） |
| `.env` 不生效 | 启动目录不是项目根目录 | 在 `e:\rag_project` 下启动 |
| VM IP 变化 | DHCP | 绑定静态 IP 或端口转发 |
