# 引用溯源与文档跳转详细实施方案

> 本文只给实施步骤、文件级改动、验收标准，不实际修改代码。
>
> 目标：回答中带上「来自哪篇文档、第几页、第几段」，并且引用可点击，直接打开原文档对应位置。
>
> 核心原则：**页码、段落、链接都来自入库元数据，大模型只输出引用编号 `[n]`，不生成页码和 URL。**
>
> 本文可独立实施；与 [扩展功能1：知识图谱构建详细实施方案.md](扩展功能1：知识图谱构建详细实施方案.md)、[扩展功能2：多模态数据处理详细实施方案.md](扩展功能2：多模态数据处理详细实施方案.md)、[扩展功能3：Agentic RAG详细实施方案.md](扩展功能3：Agentic%20RAG详细实施方案.md) 兼容。图/音频/视频的引用作为二期，见阶段七。

## 0.1 设计原则

1. **模型只出编号，不出位置**：`[1]` 是唯一允许模型生成的东西；页码、文档名、URL 全部由后端从 `source_meta` 映射。
2. **定位信息在切分后写入**：`NodeCitationEnrich` 在 `file_title_id` 已知后、向量化之前，把 `source_meta` 附加到每个 chunk。
3. **页码优先用解析器结果**：MinerU 的 `content_list.json` 有 `page_idx`，优先使用；没有再用 PyMuPDF 兜底。
4. **引用是增强，不是主链路**：页映射失败时降级为文档级引用，导入不失败。
5. **Milvus 只加一个 JSON 字段**：`source_meta`，不拆成一堆列；后续要按页过滤再拆字段。
6. **链接生成在后端**：存储 URL/对象 key，查询时拼 `#page=N`；生产用短时效签名 URL，不把内网地址暴露给外部。
7. **段落是“块”不是“自然段”**：PDF 的段号来自解析器的 block，或 PyMuPDF 的文本块；面试时要讲清口径。

## 0.2 术语与定位口径

| 术语 | 定义 |
|---|---|
| `doc_id` | `md5(file_title)`，与现有 `file_title_id` 一致 |
| `loc_type` | `pdf / md / image / audio / video / web` |
| `page_no` | PDF 页号，1 基；MinerU `page_idx + 1` |
| `paragraph_no` | 该页内的文本块序号，1 基；不是 Word 那种自然段 |
| `section` | 切片所属标题 |
| `start_ms/end_ms` | 音频/视频时间戳，二期 |
| `source_meta` | 上述信息的 JSON，存 Milvus JSON 字段 |
| `[n]` | 答案中的引用编号，后端映射到 `sources[n-1]` |

## 0.3 数据流

```text
【导入】
原始文件 → MinIO（file_url）
   ↓
NodePDFToMD → page_map.json（MinerU content_list 或 PyMuPDF）
   ↓
切分 → 主体识别（拿到 file_title_id）
   ↓
NodeCitationEnrich：每个 chunk 匹配页/块 → source_meta
   ↓
BGE-M3 → Milvus（source_meta 一起入库）

【查询】
问题 → 检索（返回 source_meta）→ RRF → Rerank（保留元数据）
   ↓
AnswerOutput：context 带 [n] + 位置标签
   ↓
LLM 只输出 [n] → 后端映射 sources → final 事件
   ↓
chat.html：行内 [n] 可点击 + 参考来源列表 → PDF #page=N
```

## 0.4 最小可用版 vs 完整版

| 版本 | 范围 | 工作量 |
|---|---|---|
| MVP | 只做 PDF；页级跳转；行内 `[n]`；参考来源列表 | 2~3 天 |
| 完整版 | 段落高亮、Markdown/音视频、图/Web 引用、历史回放、签名 URL | 1~2 周 |

建议先做 MVP，验证“页码准确率”和“引用是否真的有用”，再投入二期。

## 1.3 `source_meta` 结构

每个 chunk 写入统一结构：

```json
{
  "doc_id": "md5(file_title)",
  "file_title": "万用表RS-12的使用",
  "file_url": "http://192.168.77.77:9000/thinktank/upload_file/20261120/万用表RS-12的使用.pdf",
  "loc_type": "pdf",
  "page_no": 5,
  "page_end": 5,
  "paragraph_no": 3,
  "section": "## 直流电压档",
  "start_ms": null,
  "end_ms": null,
  "label": "《万用表RS-12的使用》第5页第3段",
  "anchor_text": "将旋钮转到直流电压档，红表笔接正极……"
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `doc_id` | 是 | 与 `file_title_id` 一致，便于按文档清理 |
| `file_title` | 是 | 展示用 |
| `file_url` | 否 | 原文件 URL；没有则只能展示文字，不能跳转 |
| `loc_type` | 是 | 决定前端怎么跳转 |
| `page_no/page_end` | PDF 必填（能定位时） | 1 基；MVP 先标起始页，二期再做跨页范围 |
| `paragraph_no` | PDF/MD 可选 | 块序号 |
| `section` | 可选 | 切片标题 |
| `start_ms/end_ms` | 音视频可选 | 毫秒 |
| `label` | 是 | 已拼好的展示文案，后端/前端直接用 |
| `anchor_text` | 可选 | 二期段落高亮用 |

## 1.4 Milvus schema 增加 `source_meta`

[minvus 入库节点](../thinktank/import_process/nodes/node_import_milvus.py) 的 schema 增加：

```python
.add_field(
    field_name="source_meta",
    datatype=DataType.JSON,
)
```

- Milvus 2.4+ 支持 JSON 字段；插入时直接传 `dict`。
- 如果版本不支持 JSON，退化为 `VARCHAR`：

```python
.add_field(
    field_name="source_meta",
    datatype=DataType.VARCHAR,
    max_length=4000,
)
```

插入前 `json.dumps(meta, ensure_ascii=False)`，查询后 `json.loads`。本方案后续代码用 `parse_source_meta` 兼容两种形式。

### 迁移方式

开发环境（数据可重导）：

1. 新建 `kb_chunks_v2`，schema 带 `source_meta`；
2. `.env` 改 `CHUNKS_COLLECTION=kb_chunks_v2`；
3. 重新导入所有文档；
4. 验证后删除旧 collection。

有数据且不能重导：

1. 新 collection 双写；
2. 后台回填旧数据（至少给 `source_meta={}`）；
3. 切读路径；
4. 保留旧 collection 一个版本周期。

> 不要直接在旧 collection 上“加字段后不填值”，Milvus 的字段默认非空，插入会报错。所有 chunk 必须至少写 `{}`。

```python
def build_page_map(self, unzip_dir_obj, pdf_path_obj):
    """
    生成页/块映射：
        1. 优先 MinerU content_list.json（有 page_idx，扫描件也有 OCR 结果）
        2. 兜底 PyMuPDF 的文本块
        3. 都失败返回空字符串，引用降级为文档级
    """
    from thinktank.tool.citation_tool import (
        build_page_map_from_content_list,
        build_page_map_from_pdf,
    )

    output_path_obj = unzip_dir_obj / "page_map.json"
    content_list_files = sorted(unzip_dir_obj.rglob("*content_list.json"))

    if content_list_files:
        try:
            path = build_page_map_from_content_list(
                content_list_files[0], output_path_obj
            )
            logger.info(f"页映射生成完成（MinerU content_list）：{path}")
            return path
        except Exception as e:
            logger.warning(f"MinerU content_list 解析失败，改用 PyMuPDF：{e}")

    try:
        path = build_page_map_from_pdf(pdf_path_obj, output_path_obj)
        logger.info(f"页映射生成完成（PyMuPDF）：{path}")
        return path
    except Exception as e:
        logger.warning(f"页映射生成失败，引用降级为文档级：{e}")
        return ""
```

> `NodePDFToMD` 原本会在解压后重命名 `full.md`，页映射文件放在同一目录，不影响后续 `NodeMDImg` 和切分。

## 2.3 新建 `thinktank/tool/citation_tool.py`

职责：页映射生成、文本定位、来源 URL 拼接、`source_meta` 兼容解析。整个项目只有这里做页/段匹配。

```python
# thinktank/tool/citation_tool.py
import hashlib
import json
import re
from pathlib import Path

from thinktank.config.config import CitationConfig
from thinktank.tool.logger import logger


def make_doc_id(file_title: str) -> str:
    """与 NodeItemNameRecognition 里的 file_title_id 保持一致。"""
    return hashlib.md5((file_title or "").encode("utf-8")).hexdigest()


def normalize_text(text: str) -> str:
    """去掉空白、标点和下划线，只保留文字/数字，便于中文匹配。"""
    return re.sub(r"[\s\W_]+", "", text or "", flags=re.UNICODE)


def build_grams(text: str, n: int) -> set[str]:
    text = normalize_text(text)
    if not text:
        return set()
    if len(text) <= n:
        return {text}
    return {text[i:i + n] for i in range(len(text) - n + 1)}


def load_page_map(page_map_path: str):
    if not page_map_path:
        return []
    path_obj = Path(page_map_path)
    if not path_obj.exists():
        return []
    try:
        with open(path_obj, "r", encoding="utf-8") as f:
            data = json.load(f)
        pages = data.get("pages", [])
        return pages if isinstance(pages, list) else []
    except Exception as e:
        logger.warning(f"读取 page_map 失败：{e}")
        return []


def prepare_page_index(pages):
    """预计算每页/每块的 n-gram，避免每个 chunk 重复计算。"""
    n = CitationConfig.page_match_ngram
    prepared = []
    for page in pages:
        blocks = page.get("blocks") or []
        prepared.append({
            "page_no": int(page.get("page_no") or 0),
            "page_grams": build_grams(
                "".join(str(block.get("text", "")) for block in blocks), n
            ),
            "blocks": [
                {
                    "block_no": int(block.get("block_no") or 0),
                    "grams": build_grams(str(block.get("text", "")), n),
                }
                for block in blocks
            ],
        })
    return prepared


def locate_in_page_map(text: str, prepared_pages):
    """
    返回 (page_no, block_no, score)。
    匹配不到返回 (None, None, 0)。
    """
    chunk_grams = build_grams(text, CitationConfig.page_match_ngram)
    if not chunk_grams:
        return None, None, 0

    best_page = None
    best_score = 0
    for page in prepared_pages:
        score = len(chunk_grams & page["page_grams"])
        if score > best_score:
            best_page, best_score = page, score

    if best_page is None or best_score == 0:
        return None, None, 0

    best_block = None
    best_block_score = 0
    for block in best_page["blocks"]:
        score = len(chunk_grams & block["grams"])
        if score > best_block_score:
            best_block, best_block_score = block, score

    block_no = best_block["block_no"] if best_block else None
    return best_page["page_no"], block_no, best_score


def _write_page_map(output_path, source: str, pages):
    output_path_obj = Path(output_path)
    output_path_obj.parent.mkdir(parents=True, exist_ok=True)
    with open(output_path_obj, "w", encoding="utf-8") as f:
        json.dump(
            {"source": source, "pages": pages},
            f,
            ensure_ascii=False,
            indent=2,
        )
    return str(output_path_obj)


def build_page_map_from_content_list(content_list_path, output_path):
    """解析 MinerU content_list.json：block 自带 page_idx。"""
    with open(content_list_path, "r", encoding="utf-8") as f:
        blocks = json.load(f)

    if not isinstance(blocks, list):
        raise ValueError("content_list 不是列表")

    pages = {}
    for block in blocks:
        if not isinstance(block, dict):
            continue

        page_idx = block.get("page_idx")
        if page_idx is None:
            continue

        text = block.get("text") or block.get("table_body") or ""
        caption = block.get("img_caption") or ""
        if isinstance(caption, list):
            caption = " ".join(str(item) for item in caption)
        text = f"{text}\n{caption}".strip()
        if not text:
            continue

        page_no = int(page_idx) + 1
        page = pages.setdefault(page_no, {"page_no": page_no, "blocks": []})
        page["blocks"].append({
            "block_no": len(page["blocks"]) + 1,
            "text": text,
        })

    page_list = [pages[key] for key in sorted(pages)]
    if not page_list:
        raise ValueError("content_list 没有可用文本块")

    return _write_page_map(output_path, "mineru_content_list", page_list)


def build_page_map_from_pdf(pdf_path, output_path):
    """兜底：PyMuPDF 按页提取文本块。扫描件可能提取不到文字。"""
    import fitz  # PyMuPDF

    pages = []
    with fitz.open(str(pdf_path)) as doc:
        for page_idx, page in enumerate(doc, start=1):
            raw_blocks = page.get_text("blocks") or []
            text_blocks = [
                block
                for block in raw_blocks
                if len(block) >= 7
                and block[6] == 0
                and str(block[4]).strip()
            ]
            text_blocks.sort(key=lambda block: (round(block[1]), block[0]))

            pages.append({
                "page_no": page_idx,
                "blocks": [
                    {"block_no": idx, "text": str(block[4]).strip()}
                    for idx, block in enumerate(text_blocks, start=1)
                ],
            })

    if not any(page["blocks"] for page in pages):
        raise ValueError("PDF 没有可提取的文本层")

    return _write_page_map(output_path, "pymupdf", pages)


def parse_source_meta(value):
    """兼容 Milvus JSON 字段（dict）和 VARCHAR 存 JSON（str）。"""
    if isinstance(value, dict):
        return value
    if isinstance(value, str) and value.strip():
        try:
            data = json.loads(value)
            return data if isinstance(data, dict) else {}
        except json.JSONDecodeError:
            return {}
    return {}


def build_source_url(meta, fallback_url: str = "") -> str:
    """把 source_meta 拼成可点击 URL：PDF 加 #page，音视频加 #t。"""
    meta = parse_source_meta(meta)
    base = meta.get("file_url") or fallback_url or ""
    if not base:
        return ""

    # 去掉已有 fragment，避免重复拼接
    base = base.split("#")[0]
    loc_type = meta.get("loc_type")

    if loc_type == "pdf" and meta.get("page_no"):
        return f"{base}#page={int(meta['page_no'])}"

    if loc_type in {"audio", "video"} and meta.get("start_ms") is not None:
        seconds = max(0, int(meta["start_ms"]) // 1000)
        return f"{base}#t={seconds}"

    return base


if __name__ == "__main__":
    import tempfile

    pages = [
        {"page_no": 1, "blocks": [{"block_no": 1, "text": "第一页讲的是睡眠时长"}]},
```

## 2.4 新建 `import_process/nodes/node_citation_enrich.py`

职责：在 `file_title_id` 已知后、向量化之前，为每个 chunk 写 `source_meta`。任何异常都降级为文档级，不影响导入。

```python
# thinktank/import_process/nodes/node_citation_enrich.py
import re
from pathlib import Path

from thinktank.config.config import CitationConfig
from thinktank.import_process.base import NodeBase
from thinktank.import_process.state import ImportGraphState
from thinktank.tool.citation_tool import (
    locate_in_page_map,
    load_page_map,
    make_doc_id,
    prepare_page_index,
)
from thinktank.tool.logger import logger


class NodeCitationEnrich(NodeBase):
    """
    引用元数据增强：
        (1) PDF：用 page_map.json 匹配页号和块号；
        (2) Markdown：用标题 + part 作为章节/段；
        (3) 图片/音频/视频：记录 media_url / 时间戳（二期）；
        (4) 匹配失败降级为文档级，不阻断导入。
    """

    name = "node_citation_enrich"

    def process(self, state: ImportGraphState):
        chunks = state.get("chunks") or []
        if not chunks:
            return {"chunks": chunks}

        file_title = state.get("file_title") or ""
        file_url = state.get("file_url") or ""
        page_map_path = state.get("page_map_path") or ""
        file_type = self.infer_file_type(state)

        prepared_pages = []
        if CitationConfig.enabled and file_type == "pdf":
            prepared_pages = prepare_page_index(load_page_map(page_map_path))

        for chunk in chunks:
            try:
                if not CitationConfig.enabled:
                    chunk["source_meta"] = self.fallback_meta(
                        chunk, file_title, file_url, file_type
                    )
                else:
                    chunk["source_meta"] = self.build_meta(
                        chunk,
                        file_type,
                        file_title,
                        file_url,
                        prepared_pages,
                        state,
                    )
            except Exception as e:
                logger.warning(f"引用元数据生成失败，降级为文档级：{e}")
                chunk["source_meta"] = self.fallback_meta(
                    chunk, file_title, file_url, file_type
                )

        logger.info(f"引用元数据完成：{len(chunks)} 个 chunk")
        return {"chunks": chunks}

    def infer_file_type(self, state: ImportGraphState) -> str:
        file_type = state.get("file_type")
        if file_type in {"pdf", "md", "image", "audio", "video"}:
            return file_type

        if state.get("pdf_path"):
            return "pdf"

        local_path = state.get("local_file_path") or state.get("md_path") or ""
        suffix = Path(local_path).suffix.lower()
        if suffix == ".pdf":
            return "pdf"
        if suffix in {".png", ".jpg", ".jpeg", ".gif", ".webp", ".bmp", ".tiff", ".tif"}:
            return "image"
        if suffix in {".mp3", ".wav", ".m4a", ".aac", ".flac", ".ogg", ".wma"}:
            return "audio"
        if suffix in {".mp4", ".mov", ".mkv", ".avi", ".webm", ".flv"}:
            return "video"
        return "md"

    def build_meta(
        self,
        chunk,
        file_type,
        file_title,
        file_url,
        prepared_pages,
        state,
    ):
        content = chunk.get("content") or ""
        section = chunk.get("title") or ""
        part = chunk.get("part") or 0
        doc_id = chunk.get("file_title_id") or make_doc_id(file_title)

        page_no = None
        page_end = None
        paragraph_no = None

        if file_type == "pdf" and prepared_pages:
            page_no, paragraph_no, _ = locate_in_page_map(content, prepared_pages)
            page_end = page_no

        loc_type = file_type
        start_ms = None
        end_ms = None
        link_url = file_url

        if loc_type == "image":
            match = re.search(r"!\[.*?\]\((.*?)\)", content)
            if match:
                link_url = match.group(1)
        elif loc_type in {"audio", "video"}:
            link_url = state.get("media_url") or file_url
            # 二期：如果 media_meta 里有 segments，可按文本匹配 start_ms/end_ms
            segments = (state.get("media_meta") or {}).get("segments") or []
            if segments:
                start_ms, end_ms = self.match_segment(content, segments)

        label = self.build_label(
            file_title, loc_type, page_no, paragraph_no, section, part, start_ms
        )

        return {
            "doc_id": doc_id,
            "file_title": file_title,
            "file_url": link_url,
            "loc_type": loc_type,
            "page_no": page_no,
            "page_end": page_end,
            "paragraph_no": paragraph_no,
            "section": section,
            "start_ms": start_ms,
            "end_ms": end_ms,
            "label": label,
            "anchor_text": content[:30],
        }

    def fallback_meta(self, chunk, file_title, file_url, file_type):
        doc_id = chunk.get("file_title_id") or make_doc_id(file_title)
        return {
            "doc_id": doc_id,
            "file_title": file_title,
            "file_url": file_url,
            "loc_type": file_type,
            "page_no": None,
            "page_end": None,
            "paragraph_no": None,
            "section": chunk.get("title") or "",
            "start_ms": None,
            "end_ms": None,
            "label": f"《{file_title}》",
            "anchor_text": (chunk.get("content") or "")[:30],
        }

    def build_label(
        self,
        file_title,
        loc_type,
        page_no,
        paragraph_no,
        section,
        part,
        start_ms,
    ):
        if loc_type == "pdf" and page_no:
            suffix = f"第{page_no}页"
            if paragraph_no:
                suffix += f"第{paragraph_no}段"
            return f"《{file_title}》{suffix}"

        if loc_type == "md":
            return f"《{file_title}》· {section or '正文'} · 第{part or 1}段"

        if loc_type in {"audio", "video"}:
            media_name = "音频" if loc_type == "audio" else "视频"
            label = f"《{file_title}》{media_name}"
            if start_ms is not None:
                label += f" {self.format_ms(start_ms)}"
            return label

        if loc_type == "image":
            return f"《{file_title}》图片"

        return f"《{file_title}》"

    def match_segment(self, content, segments):
        """二期：把 chunk 文本匹配到 ASR 分段时间戳。一期没有 segments 时返回 None。"""
        from thinktank.tool.citation_tool import build_grams

        chunk_grams = build_grams(content, 6)
        best_segment = None
        best_score = 0

        for segment in segments:
            segment_text = segment.get("text") or ""
            score = len(chunk_grams & build_grams(segment_text, 6))
            if score > best_score:
                best_segment, best_score = segment, score

        if not best_segment or best_score == 0:
            return None, None

        return best_segment.get("start_ms"), best_segment.get("end_ms")

    @staticmethod
    def format_ms(ms):
        seconds = max(0, int(ms) // 1000)
        return f"{seconds // 60:02d}:{seconds % 60:02d}"
```

> `part` 是现有切分节点里的“同一标题下的第几个切片”，不是严格自然段；MVP 用它作为段号，面试时说明口径即可。MVP 的 `page_end` 等于 `page_no`；跨页 chunk 的范围作为二期，先标起始页。

```javascript
function renderTextWithCitations(containerEl, text, sources) {
    containerEl.textContent = "";

    const sourceMap = new Map(
        (sources || []).map(s => [String(s.id), s])
    );
    const citationRe = /\[(\d+)\]/g;

    let last = 0;
    let match;
    while ((match = citationRe.exec(text)) !== null) {
        if (match.index > last) {
            containerEl.appendChild(
                document.createTextNode(text.slice(last, match.index))
            );
        }

        const source = sourceMap.get(match[1]);
        if (source && source.url) {
            const link = document.createElement("a");
            link.href = source.url;
            link.target = "_blank";
            link.rel = "noopener noreferrer";
            link.className = "citation-link";
            link.textContent = `[${match[1]}]`;
            link.title = source.label || "";
            containerEl.appendChild(link);
        } else {
            containerEl.appendChild(document.createTextNode(match[0]));
        }

        last = citationRe.lastIndex;
    }

    if (last < text.length) {
        containerEl.appendChild(document.createTextNode(text.slice(last)));
    }
}

function renderSourceList(containerEl, sources) {
    if (!Array.isArray(sources) || sources.length === 0) return;

    const wrap = document.createElement("div");
    wrap.className = "answer-sources";

    const title = document.createElement("div");
    title.className = "answer-sources-title";
    title.textContent = "参考来源";
    wrap.appendChild(title);

    for (const source of sources) {
        const link = document.createElement("a");
        link.href = source.url || "#";
        link.target = "_blank";
        link.rel = "noopener noreferrer";
        link.textContent = source.label || source.title || "来源";
        wrap.appendChild(link);
    }

    containerEl.appendChild(wrap);
}
```

- 如果通过 iframe 嵌入，确认 MinIO/CORS 允许；
- 生产环境不要把内网 MinIO 地址暴露给外部用户，改用网关或签名 URL。

# 阶段六：运维、回滚与安全

## 6.1 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 没有 `page_map.json` | MinerU zip 里没有 content_list；PDF 无文本层 | 检查 zip 内容；扫描件必须有 OCR；否则降级文档级 |
| 页码大面积错误 | n-gram 太短/太长；chunk 改写太多 | 调 `PAGE_MATCH_NGRAM`（6~10）；检查匹配分数；优先 content_list |
| 页码为空 | `page_map` 为空或匹配 0 | 看日志；检查 PDF 是否扫描件；允许文档级引用 |
| 段号不是自然段 | PDF block 不是 Word 段落 | 面试/文档里说明口径；需要自然段就做后处理 |
| 点击 PDF 变成下载 | `Content-Type` 不是 `application/pdf` | 上传时传 content_type；检查 MinIO 响应头 |
| 链接 404 | object_name/日期/文件名不对；中文未编码 | 检查 URL quote；用 MinIO 控制台确认对象 |
| 答案没有 `[n]` | 模型没遵守提示词 | 强化提示词；兜底展示前 3 个来源；换模型/温度 |
| `[n]` 指向错误来源 | 模型乱标 | 后端只按编号映射，仍可能语义错；用引用准确率评估；加引用验证 |
| 历史消息没有来源 | sources 未存 Mongo | 二期加字段；MVP 接受 |
| Milvus 插入报字段缺失 | schema 加了非空字段但没写 | 所有 chunk `setdefault("source_meta", {})` |
| Milvus 不支持 JSON | 版本旧 | 用 VARCHAR 存 JSON；`parse_source_meta` 兼容 |
| 旧 collection 没字段 | 没迁移 | 新建 v2 collection 重导；或双写回填 |
| iframe 打不开 PDF | CORS/X-Frame-Options | 配置 MinIO CORS；或新窗口打开 |

## 6.3 回滚

1. **保留字段**：Milvus 的 `source_meta` 可以继续写 `{}`，不要求删除；
2. **回滚查询/答案**：`NodeAnswerOutput` 恢复旧 context 和 final 事件；前端 `renderAnswerWithImages` 忽略 `sources` 即可；新函数可以保留；
3. **回滚导入图**：移除 `NodeCitationEnrich` 节点和边；`NodePDFToMD` 生成的 `page_map.json` 不影响原流程；
4. **回滚 schema**：如果新建了 `kb_chunks_v2`，把 `CHUNKS_COLLECTION` 切回旧表；
5. **数据**：旧表数据不受影响；新表可保留一个版本周期。

## 6.4 安全注意事项

- **文档公开性**：当前 MinIO bucket 是公开读，任何拿到 URL 的人都能看原文档。生产必须改成私有桶 + 短时效 presigned URL，或在文档服务前做鉴权。
- **权限校验**：引用链接也要走 ACL，不能让用户通过猜 URL 看到无权文档；检索阶段就要按租户/文档权限过滤。
- **内网地址**：不要把 `192.168.x.x:9000` 直接暴露给外部；用公网网关/域名。
- **提示词注入**：参考内容里可能有 `[1]` 或“忽略以上指令”；context 要分隔清楚，提示词强调只按编号引用；不要执行文档里的指令。
- **URL 编码**：中文/空格文件名必须 `quote`；避免注入非法 URL。
- **日志**：不要把完整文档内容/用户隐私写进长期日志；引用 label 可记录，正文不记录。

# 阶段七：二期扩展

## 7.1 段落级高亮

`#page=N` 只能跳页。要“打开就看到那一段”：

1. 在 `source_meta` 里存 `bbox`（MinerU/PyMuPDF 都能给文本块坐标）；
2. 前端用 PDF.js 渲染，按 `bbox` 画半透明高亮；
3. 或存 `anchor_text`，用 PDF.js 文本层搜索并滚动到匹配位置；
4. URL 形如 `viewer.html?file=...&page=5&search=旋钮转到直流电压档`。

这是“引用体验”的关键升级，但工作量明显大于页级跳转。

## 7.2 音频/视频时间戳

- FunASR 开启 `sentence_timestamp=True`，返回分段 `{text,start_ms,end_ms}`；
- `NodeCitationEnrich` 把 chunk 文本匹配到 ASR 分段，写 `start_ms/end_ms`；
- `build_source_url` 生成 `{media_url}#t=12`；
- 前端播放器 `currentTime = start_ms/1000`。

## 7.3 图/Web 引用

- 图关系带 `source_meta`，`NodeSearchGraph` 透传；
- Web 已有 URL，按网页引用展示；
- 图证据的页号需要从抽取 chunk 带过来，二期做文本匹配。

## 7.4 历史回放

Mongo 的 `chat_history` 增加 `sources` 字段；`save_chat_message` 保存，前端历史消息读取后同样渲染引用。否则刷新后来源列表丢失。

## 7.5 引用质量评估

| 指标 | 方法 |
|---|---|
| 页码准确率 | 抽 100 个 chunk 人工核对，目标 >95%（文本型 PDF） |
| 段号准确率 | 抽样核对 block 是否对应；口径要提前定义 |
| 引用合法率 | `[n]` 是否在 sources 范围内 |
| 引用支持率 | 人工/LLM 判断引用是否真的支撑该句 |
| 点击率 | 来源链接点击/会话，判断引用是否有用 |
| 无引用率 | 答案没有 `[n]` 的比例，指导提示词优化 |
