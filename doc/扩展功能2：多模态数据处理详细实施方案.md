# 多模态数据处理详细实施方案

> 本文只给实施步骤、文件级改动、验收标准，不实际修改代码。
>
> 目标：在现有 RAG 链路上增加 **图片、音频、视频** 的导入与检索能力，复用现有的 Markdown 归一化、文档切分、主体识别、BGE-M3 混合向量化、Milvus、RRF、Rerank、答案生成链路。
>
> 本文与 [扩展功能1：知识图谱构建详细实施方案.md](扩展功能1：知识图谱构建详细实施方案.md) 可独立实施，互不阻塞。若两者都实施，图谱抽取节点放在 `NodeImportMilvus` 之后即可，多模态产生的文本切片会自然进入图谱抽取。

## 0.1 设计原则（先看，决定后面所有代码）

1. **一切转 Markdown**：图片、音频、视频都先转成 Markdown 文本，再进入现有的 `NodeMDImg → NodeDocumentSplit → NodeItemNameRecognition → NodeBGEEmbedding → NodeImportMilvus`。不为每种模态新建向量表、新建检索链路。
2. **BGE-M3 仍是唯一嵌入模型**：它是文本模型。图片靠 VL 摘要进入文本，音频靠 ASR 转写进入文本，视频靠 ASR + 关键帧摘要进入文本。
3. **图片处理逻辑只保留一份**：直传图片和视频关键帧都先生成 `images/` 目录 + Markdown 图片引用，然后完全复用 `NodeMDImg` 的「VL 摘要 + MinIO 上传 + alt 替换 + URL 回填」。
4. **路由只用一个 `file_type` 字段**：不要 `is_image_read_enabled`、`is_audio_read_enabled` 一堆开关。后缀到类型的映射集中在一处，入口只做校验和路由。
5. **媒体信息只放文本，不改 Milvus schema**：把音频/视频 URL 作为文本前缀写进每个 chunk，`NodeAnswerOutput` 从 `content` 中提取。这样现有 `kb_chunks` 不需要加字段、不需要重建。后续确实要按模态过滤时再加字段。
6. **导入侧硬失败，查询侧软降级**：导入时 ffmpeg/ASR/MinIO 出问题要明确失败；查询时新增的媒体展示不能影响原有问答。
7. **所有外部输入都校验**：后缀白名单、大小上限、文件名 basename、ffmpeg 参数用列表传递（不拼 shell）。

## 0.2 范围说明

**本方案包含：**
- 直传图片（PNG/JPG/WEBP/BMP 等）入库；
- 音频（MP3/WAV/M4A 等）转写入库；
- 视频（MP4/MOV/MKV 等）抽音轨 + 关键帧入库；
- 答案中回传图片 URL、音频/视频播放链接；
- 导入页、聊天页的前端适配；
- 可选的「以图查询」接口（图片先转文字描述再检索）。

**本方案不包含（明确不做，避免过度设计）：**
- 图片向量检索（CLIP/BGE-VL）——当前靠 VL 摘要文本检索足够；只有「找相似图片」是硬需求时才另建 collection。
- 视频大模型理解——只做音轨转写 + 关键帧摘要。
- 声纹识别、说话人分离、音乐识别。
- 实时音频/视频流式处理。
- 多文件批量上传（现有接口一次一个文件）。
- 复杂 OCR——图片中的密集文字由 VL 描述可能不准，需要时单独接 PaddleOCR。

# 阶段一：基础设施与配置

## 1.1 安装 ffmpeg

音频转码、视频抽音轨、视频抽帧都依赖 ffmpeg。Windows 上任选一种：

```powershell
winget install --id Gyan.FFmpeg -e
# 或
choco install ffmpeg
```

安装后**新开一个终端**，验证：

```bash
ffmpeg -version
ffprobe -version
```

必须两个都输出正常。如果命令不在 PATH，就在 `.env` 里写绝对路径。

**验收：** 两条命令都能打印版本号。

---

## 1.2 安装 ASR 依赖

本方案默认使用 **本地 FunASR**（中文效果好、有 GPU 可用、不依赖公网可访问的音频 URL）。

```bash
uv add funasr
```

首次调用会自动从 ModelScope 下载 `paraformer-zh`、`fsmn-vad`、`ct-punc` 模型，需要能访问 ModelScope。下载过一次后会走本地缓存。

> 备选方案：DashScope 云端 `paraformer`。注意云端 ASR 需要一个**公网可访问**的音频 URL，当前 MinIO 是内网地址 `192.168.77.77:9000`，云端读不到。如果坚持用云端，需要先把音频上传到公网 OSS，再替换 `asr_tool.transcribe` 的实现。本方案不展开。

**验收：** `uv run python -c "import funasr; print(funasr.__version__)"` 能输出版本号。

## 1.3 目录与 MinIO 前缀约定

本方案统一约定：

| 内容 | 本地位置 | MinIO 位置 |
|---|---|---|
| 转出的 Markdown | `{local_dir}/{stem}/{stem}.md` | 不上传 |
| 图片/视频帧 | `{local_dir}/{stem}/images/` | `{MINIO_IMG_DIR}/{日期}/{stem}/`（复用 `NodeMDImg`） |
| 音频/视频原文件 | 上传后的本地文件 | `{MEDIA_DIR}/{日期}/{stem}/{原文件名}` |
| 查询图片（可选） | `{UPLOAD_DIR}/query_images/` | 不上传 |

其中 `stem` 是经过 `safe_stem()` 处理后的安全文件名，避免中文、空格、Windows 非法字符、括号破坏 Markdown 图片正则和 URL。

> 现有 `NodeMDImg` 的 `upload_dir` 里有一个多余空格：`f"{MinioConfig.minio_img_dir} / {日期}/{stem}"`。本方案在阶段四顺手修复，见 4.2。

# 阶段二：工具层

## 2.1 新建 `thinktank/tool/media_tool.py`

职责：安全文件名、媒体上传 MinIO、ffmpeg 封装、转 wav、探测时长、抽帧。整个项目只有这一个文件直接调 ffmpeg。

```python
# thinktank/tool/media_tool.py
import re
import subprocess
from datetime import datetime
from pathlib import Path
from urllib.parse import quote

from thinktank.config.config import MinioConfig, MultimodalConfig
from thinktank.tool.get_minio_client import get_minio_client
from thinktank.tool.logger import logger

_UNSAFE_NAME_PATTERN = re.compile(r'[\\/:*?"<>|\s]+')


def safe_stem(name: str) -> str:
    """把文件标题转成安全的目录/文件名：去掉空格和 Windows 非法字符。"""
    safe = _UNSAFE_NAME_PATTERN.sub("_", name or "").strip("._")
    return safe or "media"


def upload_media_file(local_path: str, stem: str) -> str:
    """上传音频/视频原文件到 MinIO，返回浏览器可访问的 URL。"""
    local_path_obj = Path(local_path)
    object_name = (
        f"{MultimodalConfig.media_dir}/"
        f"{datetime.now().strftime('%Y%m%d')}/"
        f"{stem}/{local_path_obj.name}"
    )

    client = get_minio_client()
    client.fput_object(
        bucket_name=MinioConfig.minio_bucket_name,
        object_name=object_name,
        file_path=str(local_path_obj),
    )
    logger.info(f"媒体文件已上传 MinIO：{object_name}")

    return (
        f"http://{MinioConfig.minio_endpoint}/"
        f"{MinioConfig.minio_bucket_name}/{quote(object_name)}"
    )


def run_ffmpeg(args: list[str]) -> None:
    """用列表参数执行 ffmpeg，不经过 shell，避免命令注入。"""
    cmd = [MultimodalConfig.ffmpeg_path, "-y", *args]
    proc = subprocess.run(cmd, capture_output=True, text=True)
    if proc.returncode != 0:
        logger.error(f"ffmpeg 执行失败：{proc.stderr[-800:]}")
        raise RuntimeError(f"ffmpeg 执行失败，返回码 {proc.returncode}")


def convert_to_wav(input_path: str, output_path: str) -> Path:
    """统一转 16k 单声道 wav，FunASR 对这个格式最稳。"""
    run_ffmpeg([
        "-i", str(input_path),
        "-vn", "-ac", "1", "-ar", "16000",
        str(output_path),
    ])
    return Path(output_path)


def probe_duration(media_path: str) -> float:
    """返回媒体时长（秒），探测失败返回 0。"""
    proc = subprocess.run(
        [
            MultimodalConfig.ffprobe_path,
            "-v", "error",
            "-show_entries", "format=duration",
            "-of", "default=noprint_wrappers=1:nokey=1",
            str(media_path),
        ],
        capture_output=True,
        text=True,
    )
    try:
        return float(proc.stdout.strip())
    except ValueError:
        logger.warning(f"无法探测媒体时长：{proc.stderr[-300:]}")
        return 0.0


def extract_frames(video_path: str, images_dir: str, interval: int) -> list[Path]:
    """每 interval 秒抽一帧，输出 frame_00001.jpg ..."""
    interval = max(1, int(interval))
    images_dir_obj = Path(images_dir)
    images_dir_obj.mkdir(parents=True, exist_ok=True)

    pattern = str(images_dir_obj / "frame_%05d.jpg")
    run_ffmpeg([
        "-i", str(video_path),
        "-vf", f"fps=1/{interval}",
        "-q:v", "2",
        pattern,
    ])
    return sorted(images_dir_obj.glob("frame_*.jpg"))


if __name__ == "__main__":
    import tempfile

    with tempfile.TemporaryDirectory() as tmp:
        tmp_obj = Path(tmp)
        video_path = tmp_obj / "demo.mp4"

        # 生成 5 秒测试视频（纯色画面 + 正弦波音轨）
        run_ffmpeg([
            "-f", "lavfi", "-i", "testsrc=duration=5:size=320x240:rate=10",
            "-f", "lavfi", "-i", "sine=frequency=440:duration=5",
            "-c:v", "mpeg4", "-c:a", "aac", "-shortest",
            str(video_path),
        ])

        wav_path = convert_to_wav(str(video_path), str(tmp_obj / "audio.wav"))
        frames = extract_frames(str(video_path), str(tmp_obj / "images"), 2)
        duration = probe_duration(str(video_path))

        assert wav_path.exists(), "wav 未生成"
        assert len(frames) >= 2, f"抽帧数量异常：{len(frames)}"
        assert duration > 0, "时长探测失败"
        print(f"media_tool smoke test passed：{len(frames)} 帧，{duration:.1f} 秒")
```

执行：

```bash

```

**验收：** 输出 `media_tool smoke test passed`。

```python
# thinktank/tool/asr_tool.py
from thinktank.config.config import MultimodalConfig
from thinktank.tool.logger import logger

_asr_model = None


def get_asr_model():
    global _asr_model

    if _asr_model is None:
        # 延迟导入：没装 funasr 时不影响其他链路
        from funasr import AutoModel

        _asr_model = AutoModel(
            model=MultimodalConfig.asr_model,
            vad_model="fsmn-vad",
            punc_model="ct-punc",
            device=MultimodalConfig.asr_device,
            disable_update=True,
        )
    return _asr_model


def transcribe(audio_path: str) -> str:
    model = get_asr_model()
    res = model.generate(
        input=audio_path,
        batch_size_s=MultimodalConfig.asr_batch_size_s,
    )
    if not res:
        return ""

    text = (res[0].get("text") or "").strip()
    logger.info(f"ASR 转写完成：{len(text)} 字")
    return text


if __name__ == "__main__":
    import sys

    assert len(sys.argv) == 2, "用法：uv run python -m thinktank.tool.asr_tool <audio.wav>"
    print(transcribe(sys.argv[1]))
```

## 3.2 重写 `import_process/nodes/node_entry.py`

入口只做三件事：校验文件、识别类型、返回路由信息。具体内容转换交给后续节点。

```python
# thinktank/import_process/nodes/node_entry.py
from pathlib import Path

from thinktank.config.file_types import detect_file_type
from thinktank.import_process.base import NodeBase
from thinktank.import_process.state import ImportGraphState
from thinktank.tool.logger import logger


class NodeEntry(NodeBase):
    """
    入口节点：
        (1) 校验文件存在、是文件、非空；
        (2) 根据后缀识别 file_type；
        (3) 只做路由，不做内容解析。
    """

    name = "node_entry"

    def process(self, state: ImportGraphState):
        local_file_path = state.get("local_file_path")

        if not local_file_path:
            logger.error("上传文件的路径不能为空")
            raise ValueError("上传文件的路径不能为空")

        file_path_obj = Path(local_file_path)

        if not file_path_obj.exists() or not file_path_obj.is_file():
            logger.error(f"上传文件不存在：{local_file_path}")
            raise FileNotFoundError(f"上传文件不存在：{local_file_path}")

        if file_path_obj.stat().st_size == 0:
            logger.error("上传文件内容为空")
            raise ValueError("上传文件内容为空")

        file_title = file_path_obj.stem
        file_suffix = file_path_obj.suffix.lower()
        file_type = detect_file_type(file_suffix)

        if file_type is None:
            logger.error(f"暂不支持的文件类型：{file_suffix}")
            raise ValueError(f"暂不支持的文件类型：{file_suffix}")

        result = {
            "file_title": file_title,
            "file_type": file_type,
            "source_path": str(file_path_obj),
        }

        if file_type == "pdf":
            result["pdf_path"] = str(file_path_obj)
        elif file_type == "md":
```

## 3.4 上传接口加固 `web/service/import_service.py`

现有接口直接用 `file.filename` 拼路径，存在路径穿越风险，也没有大小限制。媒体文件更大，必须加上。

修改 `upload` 函数：

```python
# 新增导入
from fastapi import FastAPI, UploadFile, File, BackgroundTasks, HTTPException
from thinktank.config.config import MinioConfig, MultimodalConfig
from thinktank.config.file_types import FILE_TYPE_MAP

MAX_UPLOAD_BYTES = MultimodalConfig.max_upload_mb * 1024 * 1024


@app.post("/upload")
def upload(
    background_tasks: BackgroundTasks,
    file: UploadFile = File(..., description="上传的文件"),
):
    assert file.filename is not None, "文件名不能为空"

    # 1) 只取 basename，防止 ../../ 路径穿越
    file_name = Path(file.filename).name
    file_suffix = Path(file_name).suffix.lower()
    if file_suffix not in FILE_TYPE_MAP:
        raise HTTPException(status_code=400, detail=f"不支持的文件类型：{file_suffix}")

    task_id = str(uuid.uuid4())
    add_running_task(task_id, "upload_file")
    start_time = time.time()

    file_dir_obj = Path(MultimodalConfig.upload_dir) / datetime.now().strftime("%Y%m%d")
    file_dir_obj.mkdir(parents=True, exist_ok=True)
    file_path_obj = file_dir_obj / file_name

    # 2) 分块写入 + 大小上限，避免磁盘/内存被打满
    size = 0
    try:
        with open(file_path_obj, "wb") as f:
            while True:
                chunk = file.file.read(1024 * 1024)
                if not chunk:
                    break
                size += len(chunk)
                if size > MAX_UPLOAD_BYTES:
                    raise HTTPException(
                        status_code=413,
                        detail=f"文件超过 {MultimodalConfig.max_upload_mb}MB 限制",
                    )
                f.write(chunk)
    except Exception:
        file_path_obj.unlink(missing_ok=True)
        raise

    # 3) 转储 MinIO（保持原有逻辑）
    minio_client = get_minio_client()
    minio_client.fput_object(
        bucket_name=MinioConfig.minio_bucket_name,
        object_name=f"upload_file/{datetime.now().strftime('%Y%m%d')}/{file_name}",
        file_path=str(file_path_obj),
    )
    logger.info("上传文件结束")

    add_done_task(task_id, "upload_file")
    end_time = time.time()
    add_node_duration(task_id, "upload_file", end_time - start_time)

    background_tasks.add_task(
        run_main_graph, task_id, str(file_dir_obj), str(file_path_obj)
    )
    return {"task_id": task_id}
```

要点：

- 原来写死的 `C:\Users\Administrator\Desktop\育儿` 改为 `MultimodalConfig.upload_dir`，默认 `data/uploads`，项目可移植；
- 后缀白名单来自 `file_types.py`，和入口节点保持一致；
- 文件大小超限返回 413，前端可以看到明确错误；
- 文件名只取 `basename`，避免路径穿越。

## 4.1 新建 `import_process/nodes/node_image_to_md.py`

思路：把直传图片放进 `{stem}/images/`，再写一个只包含图片引用的 Markdown。VL 摘要、MinIO 上传、alt 替换全部复用 `NodeMDImg`，不重复实现。

```python
# thinktank/import_process/nodes/node_image_to_md.py
import shutil
from pathlib import Path

from thinktank.config.file_types import IMAGE_SUFFIXES
from thinktank.import_process.base import NodeBase
from thinktank.import_process.state import ImportGraphState
from thinktank.tool.logger import logger
from thinktank.tool.media_tool import safe_stem


class NodeImageToMD(NodeBase):
    """
    直传图片转 Markdown：
        (1) 在 {local_dir}/{stem}/images/ 下放一份统一命名的图片；
        (2) 生成引用该图片的 Markdown；
        (3) 后续 NodeMDImg 负责 VL 摘要、MinIO 上传、alt 替换。
    """

    name = "node_image_to_md"

    def process(self, state: ImportGraphState):
        source_path = state.get("source_path")
        local_dir = state.get("local_dir")
        file_title = state.get("file_title")

        if not source_path or not local_dir or not file_title:
            raise ValueError("图片转 Markdown 缺少 source_path/local_dir/file_title")

        source_path_obj = Path(source_path)
        if not source_path_obj.exists():
            raise FileNotFoundError(f"图片不存在：{source_path}")

        if source_path_obj.suffix.lower() not in IMAGE_SUFFIXES:
            raise ValueError(f"不是支持的图片格式：{source_path_obj.suffix}")

        stem = safe_stem(file_title)
        work_dir_obj = Path(local_dir) / stem
        images_dir_obj = work_dir_obj / "images"
        images_dir_obj.mkdir(parents=True, exist_ok=True)

        # 统一文件名，避免中文/空格/括号破坏 NodeMDImg 的 Markdown 正则
        target_image_obj = images_dir_obj / f"image{source_path_obj.suffix.lower()}"
        shutil.copy2(source_path_obj, target_image_obj)

        md_content = (
            f"# {file_title}\n\n"
            f"![{file_title}](images/{target_image_obj.name})\n"
        )
        md_path_obj = work_dir_obj / f"{stem}.md"
        md_path_obj.write_text(md_content, encoding="utf-8")

        logger.info(f"图片已转 Markdown：{md_path_obj}")
        return {
            "md_path": str(md_path_obj),
            "md_content": md_content,
        }
```

## 5.2 新建 `import_process/nodes/node_audio_to_md.py`

流程：上传原音频到 MinIO → 统一转 16k wav → ASR 转写 → 写 Markdown → 交给 `NodeMDImg`（无图片会早退）→ 切分。

```python
# thinktank/import_process/nodes/node_audio_to_md.py
from pathlib import Path

from thinktank.config.config import MultimodalConfig
from thinktank.config.file_types import AUDIO_SUFFIXES
from thinktank.import_process.base import NodeBase
from thinktank.import_process.state import ImportGraphState
from thinktank.tool.asr_tool import transcribe
from thinktank.tool.logger import logger
from thinktank.tool.media_tool import (
    convert_to_wav,
    probe_duration,
    safe_stem,
    upload_media_file,
)


class NodeAudioToMD(NodeBase):
    """
    音频转 Markdown：
        (1) 原文件上传 MinIO，得到可播放 URL；
        (2) 统一转 16k 单声道 wav；
        (3) FunASR 转写；
        (4) 生成 Markdown。
    """

    name = "node_audio_to_md"

    def process(self, state: ImportGraphState):
        source_path = state.get("source_path")
        local_dir = state.get("local_dir")
        file_title = state.get("file_title")

        if not source_path or not local_dir or not file_title:
            raise ValueError("音频转 Markdown 缺少 source_path/local_dir/file_title")

        source_path_obj = Path(source_path)
        if not source_path_obj.exists():
            raise FileNotFoundError(f"音频不存在：{source_path}")

        if source_path_obj.suffix.lower() not in AUDIO_SUFFIXES:
            raise ValueError(f"不是支持的音频格式：{source_path_obj.suffix}")

        stem = safe_stem(file_title)
        work_dir_obj = Path(local_dir) / stem
        work_dir_obj.mkdir(parents=True, exist_ok=True)

        # 1) 原文件上传 MinIO
        media_url = upload_media_file(source_path, stem)

        # 2) 转 wav（已经是 wav 也转一次，统一采样率）
        wav_path_obj = convert_to_wav(
            source_path,
            str(work_dir_obj / "audio16k.wav"),
        )

        # 3) 转写
        transcript = transcribe(str(wav_path_obj))
        if not transcript:
            raise ValueError("音频转写结果为空，请检查音频内容")

        # 4) 写 Markdown
        md_content = (
            f"# {file_title}\n\n"
            f"> 音频文件：{media_url}\n\n"
            f"## 音频转写\n\n"
            f"{transcript}\n"
        )
        md_path_obj = work_dir_obj / f"{stem}.md"
        md_path_obj.write_text(md_content, encoding="utf-8")

        logger.info(f"音频已转 Markdown：{md_path_obj}")
        return {
            "md_path": str(md_path_obj),
            "md_content": md_content,
            "media_url": media_url,
            "media_meta": {
                "duration": probe_duration(str(source_path_obj)),
                "asr_model": MultimodalConfig.asr_model,
            },
        }
```

# 阶段六：视频支持

## 6.1 新建 `import_process/nodes/node_video_to_md.py`

流程：校验时长 → 上传原视频到 MinIO → 抽音轨转写 → 抽关键帧到 `images/` → 拼 Markdown → 交给 `NodeMDImg` 给每帧生成摘要并上传。

```python
# thinktank/import_process/nodes/node_video_to_md.py
from pathlib import Path

from thinktank.config.config import MultimodalConfig
from thinktank.config.file_types import VIDEO_SUFFIXES
from thinktank.import_process.base import NodeBase
from thinktank.import_process.state import ImportGraphState
from thinktank.tool.asr_tool import transcribe
from thinktank.tool.logger import logger
from thinktank.tool.media_tool import (
    convert_to_wav,
    extract_frames,
    probe_duration,
    safe_stem,
    upload_media_file,
)


class NodeVideoToMD(NodeBase):
    """
    视频转 Markdown：
        (1) 校验时长；
        (2) 原视频上传 MinIO；
        (3) 抽音轨 → ASR（失败时只保留关键帧）；
        (4) 每 N 秒抽一帧到 images/；
        (5) 拼 Markdown，后续由 NodeMDImg 给帧生成摘要。
    """

    name = "node_video_to_md"

    def process(self, state: ImportGraphState):
        source_path = state.get("source_path")
        local_dir = state.get("local_dir")
        file_title = state.get("file_title")

        if not source_path or not local_dir or not file_title:
            raise ValueError("视频转 Markdown 缺少 source_path/local_dir/file_title")

        source_path_obj = Path(source_path)
        if not source_path_obj.exists():
            raise FileNotFoundError(f"视频不存在：{source_path}")

        if source_path_obj.suffix.lower() not in VIDEO_SUFFIXES:
            raise ValueError(f"不是支持的视频格式：{source_path_obj.suffix}")

        duration = probe_duration(str(source_path_obj))
        if duration > MultimodalConfig.video_max_seconds:
            raise ValueError(
                f"视频时长 {duration:.0f}s 超过上限 "
                f"{MultimodalConfig.video_max_seconds}s"
            )

        stem = safe_stem(file_title)
        work_dir_obj = Path(local_dir) / stem
        images_dir_obj = work_dir_obj / "images"
        work_dir_obj.mkdir(parents=True, exist_ok=True)

        media_url = upload_media_file(source_path, stem)

        # 1) 抽音轨 + 转写；失败不影响关键帧
        transcript = ""
        try:
            wav_path_obj = convert_to_wav(
                source_path,
                str(work_dir_obj / "audio16k.wav"),
            )
            transcript = transcribe(str(wav_path_obj))
        except Exception as e:
            logger.warning(f"视频音轨转写失败，仅保留关键帧：{e}")

        # 2) 抽关键帧
        interval = MultimodalConfig.video_frame_interval
        frames = extract_frames(str(source_path_obj), str(images_dir_obj), interval)

        if not transcript and not frames:
            raise ValueError("视频未能提取到音频或关键帧")

        # 3) 拼 Markdown
        parts = [
            f"# {file_title}",
            "",
            f"> 视频文件：{media_url}",
            "",
            "## 音频转写",
            "",
            transcript or "（未检测到可转写的音频）",
            "",
            "## 视频关键帧",
        ]

        for idx, frame in enumerate(frames, start=1):
            timestamp = (idx - 1) * max(1, interval)
            parts.append(
                f"\n### 第 {idx} 帧（约 {timestamp} 秒）\n\n"
                f"![视频帧{idx}](images/{frame.name})\n"
            )

        md_content = "\n".join(parts)
        md_path_obj = work_dir_obj / f"{stem}.md"
        md_path_obj.write_text(md_content, encoding="utf-8")

        logger.info(f"视频已转 Markdown：{md_path_obj}，关键帧 {len(frames)} 张")
        return {
            "md_path": str(md_path_obj),
            "md_content": md_content,
            "media_url": media_url,
            "media_meta": {
                "duration": duration,
                "frames": len(frames),
                "interval": interval,
            },
        }
```

> 关键帧时间戳是按「第几帧 × 间隔」估算的，不是精确场景检测。够用即可；需要精确时间轴时再引入场景检测。

```python
from langgraph.graph import StateGraph, START, END

from thinktank.import_process.state import ImportGraphState
from thinktank.import_process.nodes.node_entry import NodeEntry
from thinktank.import_process.nodes.node_pdf_to_md import NodePDFToMD
from thinktank.import_process.nodes.node_md_img import NodeMDImg
from thinktank.import_process.nodes.node_image_to_md import NodeImageToMD
from thinktank.import_process.nodes.node_audio_to_md import NodeAudioToMD
from thinktank.import_process.nodes.node_video_to_md import NodeVideoToMD
from thinktank.import_process.nodes.node_document_split import NodeDocumentSplit
from thinktank.import_process.nodes.node_item_name_recognition import NodeItemNameRecognition
from thinktank.import_process.nodes.node_bge_embedding import NodeBGEEmbedding
from thinktank.import_process.nodes.node_import_milvus import NodeImportMilvus


class MainGraphRunner:
    def __init__(self):
        self.builder = StateGraph(state_schema=ImportGraphState)
        self.add_nodes()
        self.add_edges()
        self.graph = None

    def add_nodes(self):
        self.builder.add_node(NodeEntry.name, NodeEntry())
        self.builder.add_node(NodePDFToMD.name, NodePDFToMD())
        self.builder.add_node(NodeMDImg.name, NodeMDImg())
        self.builder.add_node(NodeImageToMD.name, NodeImageToMD())
        self.builder.add_node(NodeAudioToMD.name, NodeAudioToMD())
        self.builder.add_node(NodeVideoToMD.name, NodeVideoToMD())
        self.builder.add_node(NodeDocumentSplit.name, NodeDocumentSplit())
        self.builder.add_node(NodeItemNameRecognition.name, NodeItemNameRecognition())
        self.builder.add_node(NodeBGEEmbedding.name, NodeBGEEmbedding())
        self.builder.add_node(NodeImportMilvus.name, NodeImportMilvus())

    def after_entry_router(self, state):
        file_type = state.get("file_type", "")
        route_map = {
            "pdf": NodePDFToMD.name,
            "md": NodeMDImg.name,
            "image": NodeImageToMD.name,
            "audio": NodeAudioToMD.name,
            "video": NodeVideoToMD.name,
        }
        node_name = route_map.get(file_type)
        if node_name is None:
            raise ValueError(f"file_type={file_type} 暂未接入导入流程")
        return node_name

    def add_edges(self):
        self.builder.add_edge(START, NodeEntry.name)
        self.builder.add_conditional_edges(NodeEntry.name, self.after_entry_router)

        self.builder.add_edge(NodePDFToMD.name, NodeMDImg.name)
        self.builder.add_edge(NodeImageToMD.name, NodeMDImg.name)
        self.builder.add_edge(NodeAudioToMD.name, NodeMDImg.name)
        self.builder.add_edge(NodeVideoToMD.name, NodeMDImg.name)
        self.builder.add_edge(NodeMDImg.name, NodeDocumentSplit.name)
        self.builder.add_edge(NodeDocumentSplit.name, NodeItemNameRecognition.name)
        self.builder.add_edge(NodeItemNameRecognition.name, NodeBGEEmbedding.name)
        self.builder.add_edge(NodeBGEEmbedding.name, NodeImportMilvus.name)
        self.builder.add_edge(NodeImportMilvus.name, END)

    def run(self, state):
        if self.graph is None:
            self.graph = self.builder.compile()
        return self.graph.invoke(state)

    @classmethod
    def create_and_run(cls, state):
        return cls().run(state)
```

```python
def collect_media_urls(self, docs):
    """从检索结果中提取音频/视频 URL，去重保序。"""
    urls = []
    seen = set()
    for doc in docs:
        text = doc.get("content", "") or ""
        for url in self.MEDIA_URL_PATTERN.findall(text):
            if url not in seen:
                seen.add(url)
                urls.append(url)
    return urls
```

```python
import base64
import mimetypes
from pathlib import Path

from langchain.chat_models import init_chat_model

from thinktank.config.config import LLMConfig


def get_vl_model():
    return init_chat_model(
        model=LLMConfig.vl_model,
        model_provider="openai",
        api_key=LLMConfig.openai_api_key,
        base_url=LLMConfig.openai_api_base,
        temperature=LLMConfig.llm_default_temperature,
    )


def caption_image(image_path: str, hint: str = "") -> str:
    """把图片转成中文描述，供文本检索使用。"""
    image_path_obj = Path(image_path)
    mime_type = mimetypes.guess_type(str(image_path_obj))[0] or "image/jpeg"
    base64_data = base64.b64encode(image_path_obj.read_bytes()).decode("utf-8")

    messages = [
        {
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {
                        "url": f"data:{mime_type};base64,{base64_data}"
                    },
                },
                {
                    "type": "text",
                    "text": hint
                    or "请用中文简要描述这张图片的主体、场景和关键细节，100字以内，用于知识库检索。",
                },
            ],
        }
    ]
    return get_vl_model().invoke(messages).content.strip()
```

```python
def query_by_image(
    background_tasks: BackgroundTasks,
    session_id: str = Form(..., description="用户会话id"),
    file: UploadFile = File(..., description="查询图片"),
):
    assert file.filename is not None, "文件名不能为空"

    image_path_obj = query_dir_obj / f"{uuid.uuid4().hex}{suffix}"

    with open(image_path_obj, "wb") as f:
        shutil.copyfileobj(file.file, f, 1024 * 1024)

    query = caption_image(str(image_path_obj))
    if not query:
        raise HTTPException(status_code=422, detail="图片描述生成失败")

    task_id = str(uuid.uuid4())
    background_tasks.add_task(run_main_graph, task_id, query, session_id)
    return {"task_id": task_id, "query": query}
```

# 阶段九：运维、回滚与安全

## 9.1 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ffmpeg: command not found` | 未安装或不在 PATH | 安装 ffmpeg；或在 `.env` 配 `FFMPEG_PATH` |
| `ffprobe` 找不到 | 只装了 ffmpeg 没装 ffprobe | 换完整发行版；或配 `FFPROBE_PATH` |
| ASR 模型下载失败 | ModelScope 网络问题 | 配置 `MODELSCOPE_CACHE`；或把 `ASR_MODEL` 指向本地模型目录 |
| `CUDA out of memory` | ASR 和 BGE-M3 抢显存 | `ASR_DEVICE=cpu`，或调小 `ASR_BATCH_SIZE_S` |
| 音频转写为空 | 音频静音、格式异常 | 转 16k wav 后重试；检查音频内容 |
| 视频导入很慢 | 关键帧多，VL 调用有 30 RPM 限流 | 调大 `VIDEO_FRAME_INTERVAL`，调小 `VIDEO_MAX_SECONDS` |
| MinIO 图片/媒体打不开 | 内网地址；URL 未编码 | 浏览器需在同一网络；确认 URL 已 `quote`；检查 bucket 策略 |
| Milvus 插入报字段不存在 | 给 chunk 多加了 `media_url` 等键 | 本方案媒体信息只放 `content`，不要加键；要加字段需重建 collection |
| 老图片 URL 带空格 | 修复前的 `upload_dir` 有空格 | 重新导入，或手动清理旧前缀 |
| 上传返回 413 | 超过 `MAX_UPLOAD_MB` | 调大配置或压缩文件 |
| `.env` 不生效 | 启动目录不是项目根目录 | 在 `e:\rag_project` 下启动 |
| 视频报「超过上限」 | `VIDEO_MAX_SECONDS` 太小 | 调大配置或裁剪视频 |

## 9.3 回滚

本方案是增量改造，回滚按阶段：

1. **删除新节点**：移除 `NodeImageToMD`、`NodeAudioToMD`、`NodeVideoToMD` 的 import、`add_node`、条件路由项、`add_edge`。
2. **恢复入口**：把 `NodeEntry` 和 `after_entry_router` 恢复为原来的 PDF/MD 布尔开关逻辑（如果确实要回到旧版）；否则保留 `file_type` 也无害。
3. **恢复前端**：`import.html` 的 `accept` 和 `getTotalNodes`、`chat.html` 的 `renderMediaLinks` 可以保留，不会影响原功能。
4. **数据**：Milvus 中新增的多模态切片可以按 `file_title` 删除；MinIO 媒体前缀可以清理；原 PDF/MD 数据不受影响。
5. **依赖**：`funasr`、ffmpeg 不参与原链路，保留也不影响运行。

## 9.4 安全注意事项

- **后缀白名单**：只按扩展名判断，不信任客户端 MIME；需要更严格时加文件头魔数校验。
- **大小上限**：`MAX_UPLOAD_MB` 同时保护磁盘、MinIO 和 ASR 成本。
- **路径穿越**：上传文件名只取 `Path(...).name`，工作目录名用 `safe_stem`。
- **命令注入**：ffmpeg 一律列表参数，禁止 `shell=True`、禁止拼接用户输入。
- **媒体公开性**：现有 `get_minio_client` 会给 bucket 设置公开读策略，音频/视频 URL 可被匿名访问。敏感数据需要改成私有 bucket + 签名 URL。
- **时长/帧数上限**：防止超长视频导致 ffmpeg/VL 调用失控。
- **不要执行上传文件**：媒体只做转码/转写，不执行。
